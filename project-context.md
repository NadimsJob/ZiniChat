## 1. Project Overview
A multi-tenant SaaS platform enabling businesses (tenants) to manage customer communication via a unified inbox and self-serve AI Assistants across WhatsApp, Meta Messenger, and Instagram DM.
* **Primary Architecture Spec**: [full-platform-architecture-v3.md](file:///d:/ZiniChat/full-platform-architecture-v3.md) (v4 Final Production Certified)

---

## 2. Tech Stack & Environment
* **Frontend**: Next.js 16 (App Router) + TypeScript + Tailwind CSS (Unified Glassmorphism Theme)
* **Backend**: Node.js + NestJS (Modular Monolith)
* **Database**: PostgreSQL with `pgvector` extension (HNSW index optimized)
* **Queue/Cache**: Redis + BullMQ
* **Realtime**: Socket.io (namespaces for `/inbox` and `/notifications`)
* **AI Layer**: OpenAI, Anthropic Claude, & Google Gemini SDKs (BYOK & Platform-key mode)
* **Deployment**: Docker Compose + Traefik Reverse Proxy + SSL certificates (Live: `zinichat.com`, Staging: `test.zinichat.com`)

## 6. Production Deployment & Architecture Summary
* **Traefik Reverse Proxy**: Automatically routes HTTPS traffic to frontend (`:8200` live / `:8100` test) and backend (`:8201` live / `:8101` test) containers with SSL certificates.
* **Database & Queues**: PostgreSQL with `pgvector` (HNSW indexing) for AI RAG embeddings, Redis + BullMQ for asynchronous outbound messaging and broadcast job processing.
* **Storage**: Persistent Docker volume (`zinichat_backend_uploads`) mapped to `./uploads` for user avatars, media attachments, and QR code assets.
* **Deployment Protocol**: Local PC pushes code to GitHub (`git push origin main`), then invokes `scripts/invoke-mcp.js` to execute automated remote server pulls (`git pull`) and container recreation (`docker compose up -d`). Direct file transfers or unapproved `git push` actions are strictly prohibited.
